# Xray VPS Optimizer 🚀

یک اسکریپت جامع و قدرتمند برای بهینه‌سازی سرورهای لینوکسی (اوبونتو/دبیان) که به صورت ویژه برای سرورهای اکانتینگ Xray و پنل‌هایی مانند Marzban، 3x-ui، Sanaei و Hiddify طراحی شده است.

این اسکریپت با تغییر پارامترهای کرنل (Sysctl)، افزایش محدودیت تعداد فایل‌های باز (File Descriptors) تا ۱۰ میلیون، و بهینه‌سازی بافرهای شبکه، پایداری سرور شما را در مدیریت تعداد بالایی از کانکشن‌های همزمان به شکل چشمگیری افزایش می‌دهد.

## ویژگی‌ها ✨
- **مدیریت هوشمند TCP:** کاهش تایم‌اوت‌ها برای رهاسازی سریع پورت‌های اشغال شده توسط کانکشن‌های مرده.
- **افزایش سرعت:** بهینه‌سازی بافرهای رم (تا ۲۵۶ مگابایت) و صف‌های شبکه برای افزایش پهنای باند و کاهش تاخیر (Latency).
- **تنظیمات LimitNOFILE:** حذف خطای رایج `Too many open files` در ترافیک‌های سنگین.
- **پشتیبانی کامل از IPv6:** دارای MSS Clamping برای هر دو نسخه IPv4 و IPv6.
- **تشخیص خودکار پنل‌ها:** شناسایی پنل‌های مختلف (Marzban, 3x-ui, Sanaei, X-ui و...) و اعمال محدودیت‌های سیستم‌دی (Systemd) روی آنها.
- **DNS Persistence:** جلوگیری از تغییر DNS بعد از هر بار ریبوت.
- **نصب پیش‌نیازها و مدیریت Swap:** ساخت خودکار فایل Swap مناسب و نصب ابزارهای کاربردی شبکه.

## پیش‌نیازها ⚙️
- سیستم‌عامل **Ubuntu** یا **Debian**
- دسترسی کاربر **Root**

## نصب و اجرا 🛠️

برای اجرای این اسکریپت، کافیست مخزن را کلون کرده یا فایل `vps.sh` را دانلود کنید و دستور زیر را در ترمینال سرور خود وارد نمایید:

```bash
sudo bash vps.sh
```

### سایر دستورات:
- برای مشاهده وضعیت فعلی تنظیمات سیستم:
```bash
sudo bash vps.sh --status
```
- برای تنظیم مجدد DNS ها:
```bash
sudo bash vps.sh --dns
```
- برای بازگردانی به آخرین تنظیمات بکاپ گرفته شده (Restore):
```bash
sudo bash vps.sh --restore
```

## پیشنهاد ویژه 🔥
برای دستیابی به نهایت سرعت و استفاده از الگوریتم کنترل ترافیک **BBRv3**، پیشنهاد می‌شود **کرنل XanMod** را روی سرور خود نصب کنید. این اسکریپت به صورت کامل با BBR و تنظیمات پیشرفته شبکه هماهنگ است.
